# Imagens da OS 1048 (demo IC Vision)

Solte aqui os 11 arquivos da Ordem de Serviço, nomeados exatamente:

```
OS1_imagem_1.jpg
OS1_imagem_2.jpg
...
OS1_imagem_11.jpg
```

O slide de processamento carrega automaticamente (via `import.meta.glob`) e
faz o mapeamento por número. Enquanto um arquivo não existir, o card mostra um
placeholder numerado — o build não quebra.
